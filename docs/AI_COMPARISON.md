# 기록 유무에 따른 AI 비교

상단 **AI 비교**에서 실제 식물을 확보하기 전에도 가상 사례로 시작할 수 있습니다.
실제 식물 사용과 병행하는 개발 실험이며, 진단 정확도나 식물의 실제 회복 효과를 증명하는 기능은 아닙니다.

## 사용하는 순서

1. **예시 사례** 또는 **내 식물 기록**을 선택합니다. 내 기록에서는 현재 모습·질문과 공통으로 사용할 현재 사진을 입력합니다.
2. **비교 준비**로 입력을 고정합니다. 준비나 화면 이동만으로 외부 API를 호출하지 않습니다.
3. 고정한 입력과 Google 전송 안내를 확인한 뒤 동의합니다.
4. **기록 없이 분석**, **기록 포함 분석**을 각각 누릅니다. 각각 최대 1회 요청하며 둘 다 실행하면 총 2회입니다.
5. 답변의 상황 반영·구체성·이해도를 직접 평가하고 이유를 적습니다.
6. **비교 기록 내려받기**로 입력·모델·지시문·시각·응답·토큰·평가를 JSON으로 보관합니다. 사진을 사용했다면 별도로 내려받습니다.

실험은 현재 브라우저 세션에만 보관됩니다. 화면 내 메뉴 이동·재실행 시 유지되지만 새로고침·접속 종료 시 사라질 수 있습니다.
정원 전체 백업에 포함되지 않으며, 예시 식물·물주기·분석·제안을 실제 정원 DB에 추가하지 않습니다.
새 비교를 준비하면 이전 실험을 교체하고 전송 동의를 해제합니다. 먼저 파일을 내려받으세요.
내 기록과 사진이 포함된 다운로드 파일은 개인 자료이므로 공개 GitHub에 올리지 마세요.

## 두 조건에서 달라지는 것

| 조건 | 공통 입력 | 과거 정보 |
|---|---|---|
| 기록 없이 | 같은 모델·지시문·날짜·식물 이름/종류/장소·현재 질문·선택 사진 | 물주기 날짜·관리 기록·이전 제안/실행/경과 필드를 제외 |
| 기록 포함 | 위와 같음 | 최근 물주기·관리 최대 30건·이전 제안 최대 10건과 각 제안의 경과 최대 3건 |

등록 메모에는 과거 관리가 섞일 수 있어 두 조건 모두에서 제외합니다. 현재 질문에 과거 관리를 쓰면 두 조건 모두에 전달되므로 현재 상태만 적으세요.
이번 비교에는 날씨를 보내지 않습니다. 사진은 한 번 검증·축소한 동일 이미지를 두 분석에 전달하며, 다운로드에 SHA-256을 포함합니다.
한 번 고정한 입력은 식물의 이후 관리 기록이나 사례 선택이 바뀌어도 유지됩니다. **새 비교 준비**를 눌러야 교체됩니다.

버튼별 완료·실패를 기록해 재실행 때 같은 요청을 다시 보내지 않습니다. 한쪽이 실패해도 다른 결과는 남습니다.
시간 초과는 서버에서 처리됐는지 확인할 수 없으므로 자동 재시도하지 않습니다. 다시 요청하려면 새 비교를 준비하세요.
API 무료 한도나 결제 연결 상태는 앱이 확인하지 못합니다. 무료 구간 입력은 Google 제품 개선에 사용될 수 있습니다.

## 가상 사례와 참고 범위

[메릴랜드대학교 실내 식물 문제 안내](https://www.extension.umd.edu/resource/diagnose-indoor-plant-problems)는 시듦이 물 부족과 과습 모두에서 나타날 수 있다고 설명합니다.
이 점을 참고해 흙이 젖은 경우, 마른 경우, 이전 제안에 따른 실행과 이후 관찰이 있는 경우의 세 입력을 구성했습니다.
날짜·관리 기록·제안·경과는 개발용 가정이며 자료 속 실제 사례를 재현한 것이 아닙니다. 예시에는 실제 식물 사진이나 정답 AI 응답을 넣지 않았습니다.
AI는 가정된 입력에 대한 답변을 생성하며, 관찰·회복 사실을 주장해서는 안 됩니다.

평가는 사용자의 의견입니다. 기록을 포함한 답변이 무조건 더 좋다고 채점하지 않습니다.
없는 사실을 만들거나 과습/물 부족을 단정하는지, 추가 확인 조건과 다음 행동이 이해하기 쉬운지 함께 살펴보세요.
응답은 동일 조건에서도 달라질 수 있습니다. 여러 사례·반복 비교와 실제 식물 사용으로 검증을 넓히고,
현재 실험 결과를 실제 관리 효과나 정량적인 정확도로 표현하지 않습니다.
