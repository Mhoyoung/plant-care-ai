# 지역 날씨를 참고한 분석

사진·관리 기록에 **선택한 도시의 실외 날씨**를 추가로 참고합니다.
별도 날씨 API 키는 필요하지 않습니다. 주소·GPS를 수집하지 않으며 국내 14개 도시의 대표 좌표를 사용합니다.

## 사용 순서

1. 식물을 열고 **AI 분석 → 지역 날씨 함께 살펴보기**를 펼칩니다.
2. 식물을 키우는 곳과 가까운 **날씨 참고 지역**을 선택하고 **지역 저장**을 누릅니다.
3. **지역 날씨 확인**을 누르면 기온·습도·바람·강수량을 확인할 수 있습니다.
4. 질문을 입력하고 **선택한 지역의 실외 날씨 함께 참고**를 체크합니다.
5. 전송 안내에 동의하고 **Gemini로 분석**을 누릅니다.
6. 저장된 결과의 **분석 당시 참고한 지역 날씨**에서 당시 수치·기준 시각·출처를 확인합니다.

지역은 식물별로 저장하며 같은 정원을 사용하는 팀원들도 이 설정을 함께 사용합니다.
지역을 바꾸어도 이전 분석의 날씨는 바뀌지 않습니다. **지역 선택 안 함 → 지역 저장**으로 해제할 수 있습니다.

## 실외 날씨와 화분 환경

Open-Meteo의 현재 날씨는 기상 모델의 추정치이며 실내 센서 관측이 아닙니다.
도시의 실외 습도와 실내 습도는 다를 수 있고, 지역에 비가 와도 실내 화분의 흙이 젖지는 않습니다.
AI는 날씨를 추가 확인 사항을 제안하는 참고 자료로만 사용하도록 지시합니다.
물주기는 실제 흙 상태·배수·이전 기록을 확인한 뒤 결정하세요. 프롬프트만으로 AI 응답의 정확성을 보장하지 않습니다.

## 요청과 저장

- 화면 조회·지역 저장·체크박스 변경만으로 외부 API를 호출하지 않습니다.
- **지역 날씨 확인** 또는 날씨를 포함한 **Gemini로 분석** 버튼에서만 요청합니다. 자동 재시도는 없습니다.
- Open-Meteo에는 도시 대표 좌표와 요청할 날씨 항목만 보냅니다. 식물 이름·사진·관리 메모·Gemini 키는 보내지 않습니다.
- 선택한 지역과 날씨는 다른 분석 입력과 함께 Google Gemini에 전달됩니다. 전송 안내에서 이를 확인합니다.
- AI 분석 때 날씨를 다시 조회합니다. 기온(°C)·습도(%)·바람(km/h)·강수량(mm), 강수 집계 구간, 기준 시각·조회 시각·출처·한계를 당시 입력의 `outdoor_weather`에 저장합니다.
- 기준 시각은 UTC로 저장하고 화면에는 한국 시간으로 표시합니다. 강수량은 API의 `interval` 동안 누적한 값으로 표시합니다.
- 단위가 다르거나 값이 누락·범위 초과, 시각이 90분 이상 오래되거나 5분 이상 미래이면 사용하지 않습니다.
- 연결 실패·시간 초과·한도 초과 시 안내하고 `status: unavailable`을 남겨 사진·기록으로 분석합니다. 이전 날씨를 현재 값으로 대체하지 않습니다.
- 지역을 해제하거나 날씨 체크를 끄면 새 분석 입력에 날씨를 넣지 않습니다.

기존 데이터는 유지하고 `plant_weather_regions` 테이블만 추가합니다.
JSON 내보내기 형식은 기존 `schema_version: 2`를 유지하며 `weather_region`과 분석 입력의 선택적 `outdoor_weather`를 추가합니다.

## 무료 API와 검증 범위

학교 시연 등 비상업 용도로 Open-Meteo의 Free API를 사용합니다. 광고·구독·상업 서비스로 전환할 때는 사용 조건을 다시 확인해야 합니다.
날씨 수치와 함께 Open-Meteo 및 CC BY 4.0 출처를 표시합니다. Gemini 무료 구간의 한도는 별도입니다.

모의 API로 수동 요청, 전송 동의, 지역별 저장·재조회, 오류 후 분석 지속, 당시 날씨 보존을 검증합니다.
실제 식물의 경과와 날씨를 반영한 AI 응답 품질은 팀원 사용으로 추가 확인해야 합니다.
