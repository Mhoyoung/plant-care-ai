## 차별화 방향의 가설

마스코트·AI 상담·사진 진단·관리 기록·날씨 자체를 우리만의 기능이라고 설명하지 않습니다.
특히 AI Plant Doctor는 관리 계획과 경과 추적도 소개하므로 기록 기능의 유무만으로 차별화를 주장하기 어렵습니다.

우리는 다음 사용 흐름을 구체적으로 구현하고 검증합니다.

- 사용자가 먼저 확인할 조건을 짧고 읽기 쉽게 안내합니다.
- 어떤 이전 기록·실행·이후 관찰을 참고했는지 확인할 수 있게 합니다.
- 제안이 존재하는 것과 실제로 실행한 것을 구분하고 이후 경과를 다음 분석에 전달합니다.
- 같은 현재 상태·사진의 기록 제외/포함 답변을 비교해 상황 반영과 이해도를 평가합니다.

이는 제품의 강조점과 검증할 가설입니다. 다른 앱에 이 흐름이 없다고 단정하지 않습니다.
실제 식물을 사용하는 팀원에게 기록하기 쉬운지, 다음 행동을 이해할 수 있는지, 반복 관리에 도움이 되는지 확인해야 합니다.

## 이번 화면에 적용

새싹 아이콘과 짧은 안내 → 확인 카드 최대 3개 → 추가 확인/조건부 관리 → 분석의 한계/전체 원문 순서로 표시합니다.
짧은 안내는 원문의 첫 확인 항목에서 탐색용 제목을 붙이는 화면 안내이며 새 진단이나 별도 AI 요약 호출이 아닙니다.
원래 상태 요약·관찰·모든 확인·조건부 제안·불확실성은 전체 분석에서 그대로 볼 수 있습니다.
원문의 순서와 조건을 유지하고, 두 비교 조건에도 동일한 표시 규칙을 적용합니다.

다른 앱의 이름·캐릭터·사진·점수 화면을 가져오지 않고 현재 앱의 초록/아이보리 디자인 안에서 구현했습니다.
마스코트의 이름·성격·움직임은 관리 흐름에 대한 사용성 확인 후 다듬습니다.
